# Apple Silicon の依存ライブラリ表示候補

2026年10月17日のローカル Apple Silicon ビルド環境から、インストール済み Python 配布物のメタデータと、その `.dist-info` にあるライセンス／通知ファイルを収集しました。V10 バイナリの中身と 1:1 に突き合わせたものではありません。Intel Mac、Windows、Python本体、Qt、フォント、JavaScript等の全ライセンスも網羅していません。配布物にこの候補をそのまま「完全」として表示しないでください。

確認した Python 配布物: 95件。ライセンス／通知ファイルが見つからなかった配布物: 5件。

2026年10月19日、上記5件は対応する上流ソースのライセンスファイルを収集し、`INVENTORY.csv` に記載しました。Python配布物95件の候補一覧ではライセンス本文の空欄は0件です。ただし、候補にはアプリへ同梱されないビルド専用パッケージも含まれ、アプリ中のPython本体、Qt、フォント、JavaScript、ネイティブライブラリを含む全体監査は未完了です。
